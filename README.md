# เว็บรับบัตรคิว (เวอร์ชันสาธารณะ ไม่ต้องล็อกอิน Claude)

ทุกคนที่เปิดลิงก์นี้จะได้เลขคิวจากตัวนับกลางเดียวกัน (Q001, Q002, ...) ไม่ซ้ำกัน แม้กดพร้อมกันหลายคน

## ขั้นตอนที่ 1 — ตั้งฐานข้อมูล (Supabase, ฟรี)
1. สมัคร/ล็อกอิน https://supabase.com แล้วสร้างโปรเจกต์ใหม่ (เลือก region ใกล้ ๆ เช่น Singapore)
2. ไปที่เมนู **SQL Editor** > New query > เปิดไฟล์ `supabase-setup.sql` ในโฟลเดอร์นี้ คัดลอกทั้งหมดไปวาง แล้วกด Run
3. ไปที่ **Project Settings > API** คัดลอกค่า 2 ตัว:
   - `Project URL`
   - `anon public` key

## ขั้นตอนที่ 2 — ใส่ค่าในโค้ด
เปิดไฟล์ `index.html` หาบรรทัดนี้ใกล้ด้านบนของ `<script>`:
```js
var SUPABASE_URL = "YOUR_SUPABASE_URL";
var SUPABASE_ANON_KEY = "YOUR_SUPABASE_ANON_KEY";
```
แทนที่ด้วยค่าจริงที่คัดลอกมา แล้วบันทึกไฟล์

## ขั้นตอนที่ 3 — Deploy ขึ้น Vercel
วิธีที่ง่ายที่สุด (ไม่ต้องใช้ Git):
1. ติดตั้ง Vercel CLI เครื่องคุณ: `npm i -g vercel`
2. เปิด Terminal ไปที่โฟลเดอร์นี้ (ที่มีไฟล์ `index.html`)
3. รันคำสั่ง `vercel` แล้วตอบคำถามตามค่า default (ครั้งแรกจะให้ล็อกอิน Vercel ก่อน)
4. รันคำสั่ง `vercel --prod` เพื่อขึ้นเว็บจริงที่ `*.vercel.app`

หรือถ้าถนัด GitHub: push โฟลเดอร์นี้ขึ้น repo แล้วไปที่ vercel.com > Add New Project > Import จาก GitHub repo นั้น (ไม่ต้องตั้งค่า build command ใด ๆ เพราะเป็นไฟล์ static ล้วน)

## หมายเหตุ
- ปุ่ม "เริ่มรันคิวใหม่" จะรีเซ็ตเลขคิวกลับไปเริ่มที่ Q001 ให้ทุกคนที่เปิดหน้านี้อยู่เห็นผลทันที
- ฐานข้อมูลไม่เก็บข้อมูลส่วนตัวของลูกค้า เก็บแค่ตัวเลขคิวถัดไปเท่านั้น
- ฟรีของ Supabase เพียงพอสำหรับงานนี้สบาย ๆ (การเรียก API ระดับหลักพัน/วัน)
